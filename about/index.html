我是谁

你好，我是压轴戏。平时喜欢写点代码，也喜欢研究和折腾自己感兴趣的东西。

平时会写点代码、研究自己感兴趣的工具，也会花不少时间折腾这个博客。很多内容都是一边学、一边试，再把真正弄明白的部分记下来。

我不太想把这里做成只展示结果的地方。比起贴一份能运行的代码，我更想留下当时为什么这么做、哪里容易出错，以及最后是怎么解决的。

这个博客

博客开始于 2023-11-16。

最开始只是想有一个能长期放文章的地方，后来页面、主题、部署和各种小功能越改越多，也慢慢变成了自己的长期项目。

目前主要会记录这些内容：

  • 算法学习和题目整理；
  • Hexo、Butterfly 以及博客维护过程；
  • 用过的工具、踩过的问题和解决办法；
  • 一些暂时还不好归类，但值得留下来的东西。

文章不一定写得很快，但会尽量保证以后自己再回来时还能看懂。

博客环境

  • Hexo 8
  • Butterfly 5.7
  • Node.js 24 LTS
  • GitHub 分别管理源码和静态部署产物
